## Project Structure

## Git Workflow in VS Code
1. Створення ізольованих гілок завдань (`feature-style`, `feature-docs`).
2. Контроль версій через Staging Area (`+`), інформативні повідомлення комітів.
3. Злиття гілок (`Merge Branch`) з вирішенням конфліктів у 3-way Merge Editor.
4. Відновлення та скасування змін (`Revert Commit`, `Undo Last Commit`, `Discard Changes`).
5. Синхронізація з GitHub через асинхронний `Fetch`, злиття через `Pull` та відправка через `Push`.
